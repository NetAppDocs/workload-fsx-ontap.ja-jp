= NetApp Workload Factoryのリソースのコストを追跡する
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp Workload Factoryを使用してFSx for ONTAPファイルシステムのコストと使用状況を追跡することで、予算を管理し、リソースを効果的に最適化できます。最小限の権限を必要とするデータで全体的なコストを提供するために、AWS Cost Explorerを使用しています。リソース（ファイルシステムまたはボリューム）ごとのコストはWorkload Factoryの計算に基づいており、AWS Cost Explorerでは得られない独自のインサイトを提供します。



[[about-this-task]]
== タスクの内容

Workload Factory は、以下の権限を使用して AWS Cost Explorer から FSx for ONTAP ファイルシステムリソースのコストと使用状況データを取得します： `ce:GetCostAndUsage` および  `ce:GetTags`。以下のコスト詳細が追跡されます：使用タイプ、使用 SKU、デプロイメントタイプ、使用量、および合計コスト。

コストダッシュボードには、全体コストとリソース別のコストを表示する2つのタブがあります。

* 総コストは、AWS Cost Explorer APIから直接取得したデータに基づいています。
* リソース別コストでは、ファイルシステムまたはボリュームごとのコスト見積もりが表示されます。
+
固有のリソースの場合、Workload Factory は、実際のパフォーマンスティアの使用状況、プロビジョニング済みだが未使用のスペースに割り当てられたパフォーマンスティアコストの比例配分、容量ごとに分配されたパフォーマンス割り当て、および容量プールの使用状況を組み合わせてコストを計算します。Workload Factory は、各コンポーネントにそのディメンションにおける単価を乗算し、その結果を合計して各リソースの総コストを決定します。



Workload Factoryは常に月単位でデータを表示します。

AWSアカウント、認証情報、1つ以上のリージョン、および期間でコストと使用状況データをフィルタリングして、FSx for ONTAPファイルシステムの使用量を把握できます。1つ以上のファイルシステム、およびファイルシステム内の1つ以上のボリュームでフィルタリングすることもできます。

AWSのコスト配分タグキーとタグキー値により、特定のコストを特定するためのフィルタリングのレイヤーが追加されます。_タグ_はキーと値で構成されます。タグキーとタグキー値でフィルタリングするには、FSx for ONTAPファイルシステムにタグを割り当てます。link:https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/cost-alloc-tags.html["AWSのコスト配分タグについて詳しくはこちらをご覧ください。"^]

コストダッシュボードのコストデータに加えて、AIが生成したコストエグゼクティブサマリーには、FSx for ONTAPファイルシステムのコストと組織の支出パターンが表示されます。FSx for ONTAPファイルシステムリソースのCSVファイルを生成して、チームや関係者と共有できます。



[[track-costs]]
== コストを追跡する

Workload Factory コンソールのコストダッシュボードに表示されるコストは、AWS Cost Explorer のデータに基づいており、24時間ごとに更新されます。

.開始する前に
以下の要件を満たしていることを確認してください。

* Workload Factory で FSx for ONTAP のコストを追跡するには、link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["_表示、計画、および分析_権限ポリシーで資格情報を付与する"^]必要があります。
* AWS割り当てタグでフィルタリングするには、FSx for ONTAPファイルシステムにタグが割り当てられていることを確認してください。


.手順
. いずれかを使用してログインしlink:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["コンソールエクスペリエンス"^]ます。
. メニューを選択 image:workloads-menu-icon.png["ハンバーガー メニュー アイコンは、ストレージ、eda、ai、データベース、vmware、管理などのワークロードに移動するために使用されます。"] 次に*ストレージ*を選択します。
. ストレージメニューから*コスト*を選択します。
. コストダッシュボードから、以下の情報を指定して FSx for ONTAP リソースのコストと容量データをフィルタリングします。
+
.. *AWS アカウント*: コストデータを表示するアカウントを選択します。
.. *資格情報*: _表示、計画、および分析_権限を持つ資格情報を選択します。
.. *リージョン*: コストデータを表示する AWS リージョンを選択します。
.. *コスト データ範囲*: 表示するコスト データの期間を選択します。
.. *割り当てタグキー*：（オプション）割り当てタグキーとその値を選択して、AWS タグに関連付けられたすべての FSx for ONTAP ファイルシステムの詳細なコストレポートを生成します。
.. *割り当てタグ値*：（オプション）割り当てタグキーに関連付けられた割り当てタグキー値を選択して、AWS タグに関連付けられたすべての FSx for ONTAP ファイルシステムの詳細なコストレポートを生成します。


. FSx for ONTAPリソースの *コストの詳細* を表示します。




[[generate-cost-reports-for-your-fsx-for-ontap-resources]]
== FSx for ONTAP リソースのコストレポートを生成する

特定の FSx for ONTAP ファイルシステムリソースのコストレポートを生成し、関係者と共有します。

.手順
. コストダッシュボードで、*レポートの生成*を選択します。
. レポート画面で、以下の情報を入力してください。
+
.. *ファイルシステム*：レポートに含める FSx for ONTAP ファイルシステムを1つ以上選択してください。
.. *ボリューム*：（オプション）レポートに含めるボリュームを1つ以上選択します。




.結果
Workload Factoryは、ダウンロード可能なCSVレポートを生成します。
